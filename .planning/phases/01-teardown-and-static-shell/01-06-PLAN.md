## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contributor commit to public repo | a secret committed by mistake becomes public |
| build output to the wallet-allowlisted origin | anything in out/ is served where the wallet trusts page scripts |
| npm advisory database to CI | audit results decide whether the build ships |
| GitHub release download to CI runner | the gitleaks binary runs with repo read access |
| pull request to CI | untrusted code runs in the workflow |
