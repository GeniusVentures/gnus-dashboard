Proves roadmap criteria 1 and 5 (SHELL-09) against the built files, not the dev server.

`scripts/serve-out.js` uses Node built-ins only (http, fs, path). It is the "plain static file server" of criterion 1, and research STACK.md names this file for the phase 7 CSP work.
- It serves the `out/` folder next to the repo root on 127.0.0.1, port `PORT` or 4173. It exits with a clear message if out/ is missing.
- GET and HEAD only; any other method gets 405.
- It decodes the pathname (400 on a malformed escape) and resolves it against the out/ root. A resolved path outside out/ (dot segments, encoded dot segments, backslashes) gets the 404 response and is never read.
- Lookup order: the exact file, then the path plus ".html", then the path plus "/index.html". "/" serves index.html. Anything else gets out/404.html with status 404.
- Content-Type comes from a small extension map (html, js, css, json, png, svg, ico, woff, woff2, ttf, mp4, txt), defaulting to application/octet-stream. Every response sends `X-Content-Type-Options: nosniff`.
- No caching or CSP headers here; those belong to phase 7.

`cypress.config.js`: `defineConfig` from cypress, with e2e baseUrl `http://127.0.0.1:4173`, `supportFile: false`, specPattern `cypress/e2e/**/*.cy.js` and `video: false`. Add `cypress/screenshots` and `cypress/videos` to `.gitignore`.

`cypress/e2e/static-shell.cy.js`:
- Register an intercept for any `/api/` path as an alias. At the end of every test, assert the alias saw zero calls.
- For each of the five routes, visit it, assert the h1 text and the document title, and assert the nav has links to /submit, /jobs and /earnings and none to /analytics, /job-orders or /wallet.
- 404: `cy.request` an unknown path with `failOnStatusCode: false` and expect status 404. Then visit it with the same option and assert the "Page not found" h1.

package.json scripts:
- `serve:out` runs `node scripts/serve-out.js`.
- `cy:run` runs `cypress run`.
- `test:e2e` runs `start-server-and-test serve:out http://127.0.0.1:4173 cy:run`.
Script names avoid shell quoting, which breaks under cmd.exe on Windows.

Run `yarn build`, then `yarn test:e2e`. If Task 0 of 01-01 recorded that Cypress cannot launch headless here, still commit the harness. Instead of the run:
- Start serve-out and curl each route, expecting 200 and its h1 text in the body, and the unknown path, expecting 404.

In every case, run the traversal checks with curl `--path-as-is` against the running server. `/../package.json` and `/%2e%2e/package.json` must both return 404, and the body must not contain the package name.
