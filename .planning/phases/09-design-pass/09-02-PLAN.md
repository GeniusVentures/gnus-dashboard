# 09-02 — Adopt the gnus.ai design language

The dashboard's wave-1 pass invented a light teal theme. The product's own
marketing site (gnus.ai) has a defined look and the user asked to reuse it.
Reference: http://slave:8099/2026-11-10/151059-gnusai-top.png and the extracted
palette of the site's compiled CSS.

## The gnus.ai system (from the site)

- Dark near-black page (#0b1324 slate scale — the dashboard's grays already
  come from it), green-tinted glow behind the hero, dotted grid texture.
- Mint #36edb5 is the CTA fill **with near-black text**, pill-shaped, weight 600.
  The wave-1 lesson inverted: mint was never a white-text fill — on dark it
  passes contrast as-is.
- Secondary: transparent pill, thin light border, light text. Tertiary chips:
  dark pills, ~15% white border.
- Panels: slightly-lightened surfaces (#1e293b family), 20-24px radius, flat —
  no shadows, no borders where a lighten alone separates.
- Type: Space Grotesk (display/headings, 600-700), Inter (body), Space Mono
  (mono). Uppercase 12-13px bold letter-spaced micro-labels.
- Headline accent: the key phrase set in mint.

## Requirements

- R1 `data-bs-theme="dark"` on <html>; brand colours restored: $primary back to
  mint #36edb5 (bootstrap's color-contrast then picks dark text on mint fills).
- R2 Fonts via fontsource: Space Grotesk (headings), Inter (body), Space Mono
  (mono) — replacing the Roboto/hkModular default.
- R3 Pill buttons (radius 999px, weight 600) for .btn; secondary = outline pill.
- R4 Page background #0b1324 with a mint-tinted radial glow behind the hero;
  panels on #1e293b family, 20px+ radius, border-subtle, no shadows.
- R5 Hero headline carries one mint accent phrase; uppercase micro-labels for
  section titles (identity cards, steps, status).
- R6 All 09-01 component classes (address pill, status pill, hero metric,
  empty state, steps) recoloured for dark via bootstrap variables, not hex.

## Out of scope

Dotted-grid texture image, constellation art (needs an asset from the site's
build — flagged as an asset ask), light-mode support.
