# 09-01 — Design pass: make the dashboard look like a product

Persona audit evidence: `09-01-PERSONA-AUDIT.md` (screenshots: http://slave:8099/2026-11-10/140035-ui-*.png).
Verdict across four pages: no type scale, mint-on-white buttons failing contrast,
no primary/secondary action hierarchy, raw header data dump, dead-space pages,
empty states with no structure, pink/teal palette clash.

## Scope

One visual pass over the four paired pages (landing, submit, my jobs, earnings),
the shared header/footer, and the theme layer. No routing, no contract, no copy
rewrites beyond the empty states. CSP stays closed: classes only, no inline styles.

## Requirements

- R1 Contrast-safe brand: `$primary` moves from `#36edb5` (white text ≈1.9:1) to
  `#0b6e8f` (the wallet's own light-mode connect colour, ≈5.8:1). Mint stays as an
  accent only.
- R2 A design-pass stylesheet (`_designpass.scss`): address pill, network badge,
  status pill, hero metric (tabular numerals), empty state, step list, identity bar.
- R3 Header groups three concerns: brand | nav (with active state) | identity
  (earning chip, paying chip, network badge, Disconnect). No naked "Copy" links —
  the chip carries a copy control with copied feedback.
- R4 Network names are human: chain 80002 → "Amoy testnet"; unknown falls back to
  the chain id. The word "staging" stays out of the UI (dev-only env badge).
- R5 Landing is a hero: one headline, one sentence, primary CTA to submit,
  secondary to my jobs, and the earning/paying explainer as a designed two-up
  block instead of quoted jargon.
- R6 Submit: content column ≤ 720px, three labelled steps, estimate result inline
  above the pay action, pay = primary / estimate = outline.
- R7 My jobs empty state: icon, headline, subtext, primary CTA — centred.
- R8 Earnings: balance as a hero metric with a status pill, refresh beside the
  data it refreshes, history empty state instead of bare rules.
- R9 Footer socials muted (small, secondary colour).

## Out of scope

Dark mode, new fonts, the OrderForm rewrite, populated jobs table design (next
plan), copy edits beyond empty states.
